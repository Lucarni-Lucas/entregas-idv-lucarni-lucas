# Entrega 4

## Desafío 5 — State Machine, Arquitecturas e IA

[Jugar en el navegador](https://lucarni-lucas.github.io/entregas-idv-lucarni-lucas/entrega-4/)

Extiende la State Machine del Player con el estado "Jump" y le da movimiento
por el entorno al enemigo mediante pathfinding A*. Si a la torreta no se le
asigna un nodo de pathfinding, se queda quieta.

Incluye los bonus: State Machine propia para el enemigo (idle / walk / alert / die)
y el estado "Dash" del Player.

## Controles

| Acción | Tecla |
| --- | --- |
| Mover | `A` / `D` o `←` / `→` |
| Saltar | `Espacio`, `W` o `↑` |
| Disparar | Click izquierdo |
| Dash | `Shift` o `E` |
| Ver área de detección del enemigo | `T` |
| Reiniciar nivel | `R` |
