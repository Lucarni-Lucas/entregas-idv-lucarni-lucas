# Entrega 5

## Desafío 6 — UI y UX

[Jugar en el navegador](https://lucarni-lucas.github.io/entregas-idv-lucarni-lucas/entrega-5/)

Agrega un menú de Opciones que lista los controles del juego, accesible tanto
desde el Menú Principal como desde el menú de Pausa. Los menús pausan y despausan
el juego al aparecer, y desde la Pausa se puede volver al Menú Principal. La barra
de salud del jugador se extendió para mostrar también la Mana y la Stamina.

## Controles

| Acción | Tecla |
| --- | --- |
| Mover | `A` / `D` o `←` / `→` |
| Saltar | `Espacio`, `W` o `↑` |
| Dash | `Shift` |
| Atacar (arma 1) | Click izquierdo |
| Atacar (arma 2) | Click derecho |
| Atacar (arma 3) | Click central o `R` |
| Arma siguiente | Rueda arriba o `E` |
| Arma anterior | Rueda abajo o `Q` |
| Pausa | `Esc` |
| Ver área de detección del enemigo | `T` |
