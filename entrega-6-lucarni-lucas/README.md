# Entrega 6

## Desafío 7 — Sonido

[Jugar en el navegador](https://lucarni-lucas.github.io/entregas-idv-lucarni-lucas/entrega-6/)

Agrega sonido a las acciones del personaje (pasos, salto, aterrizaje, dash, daño,
muerte y los tres ataques de cada arma), a las de los enemigos (alerta, ataque,
daño y muerte), y música de fondo al nivel, al menú principal y a la pantalla de
derrota.


## Controles

| Acción | Tecla |
| --- | --- |
| Mover | `A` / `D` o `←` / `→` |
| Saltar | `Espacio`, `W` o `↑` |
| Dash | `Shift` |
| Atacar (arma 1) | Click izquierdo |
| Atacar (arma 2) | Click derecho |
| Atacar (arma 3) | Click central o `R` |
| Arma siguiente | Rueda arriba o `E` |
| Arma anterior | Rueda abajo o `Q` |
| Pausa | `Esc` |
| Ver área de detección del enemigo | `T` |
